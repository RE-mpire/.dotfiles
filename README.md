# dotfiles

My dotfiles and configs

## Requirements

Ensure you have the following installed on your system:

**On Arch Linux:**
```
pacman -S git stow
```

**On macOS:**
```
brew install git stow
```

## Installation
To install the dotfiles, clone the repository and run the install script, which uses GNU Stow to symlink the files into your home directory:
 
```
$ git clone git@github.com:RE-mpire/.dotfiles.git
$ cd .dotfiles
$ ./install.sh
```
 
If stow reports a conflict, a real file is already in the way (for example an existing `~/.zshrc`). Nothing is overwritten. Move or delete that file and rerun `./install.sh`
 
Pass `-v` to see what stow is doing: `./install.sh -v`
 
## Skipping files on a machine
 
Not every machine needs every config (for example, a zsh machine doesn't need `.bashrc`). Which files are linked is controlled by:
 
| File                 | Purpose                                                         |
| ---                  | ---                                                             |
| `stow-ignore.base`   | Ignores shared by every machine (README, `.git*`, repo tooling) |
| `stow-ignore.local`  | Ignores for this machine only                                   |
| `.stow-local-ignore` | Generated by `install.sh` from the two above. **Don't edit it.**    |
 
To skip files, add one Perl regex per line to `stow-ignore.local` and rerun `./install.sh`. Files you add are unlinked automatically.
 
```
# zsh machine: don't link bash config
^/\.bashrc
^/\.bash_profile
 
# don't link nvim here
^/\.config/nvim
```
 
`^/` anchors the pattern to the top of the repo, and `.` must be escaped as `\.`. Without `^/`, a pattern matches a file or directory name anywhere in the repo.
 
To link a file again, delete its line and rerun `./install.sh`.
